基于 RK3568 的多媒体终端一体机

这是一个基于 RK3568 开发板构建的多媒体终端系统，主要用于展示和运行各类多媒体与人机交互功能。项目采用纯 C 语言开发，图形界面基于 **LVGL** 图形库构建。

 ✨ 主要功能
本项目集成了多个功能模块，可通过主界面进行切换：
* **聊天模块 (`chat.c`)**：实现基础的终端聊天交互功能。
* **游戏模块 (`game.c`)**：内置小游戏，包含锤子/星星等自定义图标 (`hammer_img.c`, `star_img.c`)。
* **音乐播放 (`music.c`)**：支持音频文件播放及控制。
* **视频播放 (`video.c`)**：支持视频文件的解码与播放。
* **登录验证 (`login.c`)**：用户登录界面及权限控制。
* **系统设置 (`settings.c`)**：提供系统参数配置面板。
* **UI 框架 (`ui.c`, `globals.h`)**：管理界面布局、鼠标光标、自定义字体(`lv_myfont_30.h`)等。

## 🛠️ 硬件与环境要求
* **开发板**：RK3568 核心板/开发板
* **屏幕**：适配 LVGL 的 LCD 触摸屏（分辨率需根据实际配置）
* **交叉编译器**：`aarch64-linux-gnu-gcc` (或其他适配 RK3568 的工具链)
* **依赖库**：LVGL (版本需根据 `lv_conf.h` 实际配置确定)

## 🚀 编译与运行
**注意**：本项目为 RK3568 交叉编译项目，无法在普通 PC 上直接编译运行。

1. 确保已配置好 RK3568 的交叉编译工具链。
