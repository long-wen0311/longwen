基于 RK3568 的多媒体终端一体机

这是一个基于 RK3568 开发板构建的多媒体终端系统，主要用于展示和运行各类多媒体与人机交互功能。项目采用纯 C 语言开发，图形界面基于 **LVGL** 图形库构建。

 ✨ 主要功能
本项目集成了多个功能模块，可通过主界面进行切换：
## 📂 目录结构说明
```text
├── main.c                  # 程序主入口，负责初始化与主循环
├── chat.c                  # 聊天功能模块（原文件名为“聊天室”，需改为 chat.c）
├── game.c                  # 游戏功能模块（原 Game.c，建议改小写）
├── music.c                 # 音乐播放模块
├── video.c                 # 视频播放模块
├── login.c                 # 登录验证模块
├── settings.c              # 系统设置模块
├── ui.c                    # 图形界面核心逻辑（原 UI.C，建议改小写）
├── globals.h               # 全局变量声明（原“全球 (Globals.H)”，需改为 globals.h）
├── lv_conf.h               # LVGL 配置文件
├── lv_myfont_30.h          # 自定义中文字体
├── hammer_img.c            # 游戏锤子图片资源
├── star_img.c              # 游戏星星图片资源
└── mouse_cursor_icon.c     # 鼠标光标图片资源

## 🛠️ 硬件与环境要求
* **开发板**：RK3568 核心板/开发板
* **屏幕**：适配 LVGL 的 LCD 触摸屏（分辨率需根据实际配置）
* **交叉编译器**：`aarch64-linux-gnu-gcc` (或其他适配 RK3568 的工具链)
* **依赖库**：LVGL (版本需根据 `lv_conf.h` 实际配置确定)

## 🚀 编译与运行
**注意**：本项目为 RK3568 交叉编译项目，无法在普通 PC 上直接编译运行。

1. 确保已配置好 RK3568 的交叉编译工具链。
2. 在项目根目录执行编译（请确保已正确编写 `CMakeLists.txt` 或 `Makefile`）：
   ```bash
   mkdir build && cd build
   cmake ..
   make
